Karena demo ini dijalankan di localhost, sesuaikan variabel LOCAL_IP dengan IP local (cek ipconfig untuk windows, untuk os lain sesuaikan commandnya)

Jalankan server ----> node server

Buka browser & arahkan ke url http://localhost:3000
Lalu masuk sebagai Pennyiar, klik Mulai Live Streaming (ada validasi kamar, silahkan pilih kamar)

Buka browser lain & arahkan ke url http://localhost:3000
Lalu masuk sebagai Penonton, klik Tonton Siaran (pilih kamar yang dipilih streamer sebelumnya)
